## Open question: `CAP_*` directories

`design/fabulous/Tile/` holds `CAP_E/N/S/W` next to `LOGIC4`. They are
non-logic boundary terminators (wire loop-backs, no BELs). The FABulous
generator cannot take a bare single-tile `fabric.csv`: edge wires must land on
a tile (sibling `design/README.md` "Discrepancies", item 2, and ADR-0004,
*Proposed*).

Resolution here: the `CAP_*` directories are **stamped**, because the stamped
`fabric.csv` references them and omitting them would fail the generator.
They are harness-only boundary cells, not logic tile types, so "single tile
type" is read as "single logic tile type". This reading is the sibling's
unratified proposal. It is recorded as inherited-*Proposed* in ADR-0001, not
as a ratification, and it is not a licence to add tile types. If the sibling's
ADR-0004 is decided differently, this repo follows it through a new decision
record.

## `reuse.lock.json` schema

Defined here; the sibling has no precedent file.

```json
{
  "schema_version": 1,
  "source_repo": "2AMLogic/sky130-fpga",
  "source_commit": "<40-hex sha>",
  "files": [
    { "path": "<path in source repo>",
      "sha256": "<sha256 of the file content>",
      "mode": "vendored",
      "destination": "<path in this repo>" }
  ]
}
```

`sha256` is the digest of both the sibling's file at `source_commit` and the
copy at `destination`. A file whose copy has diverged has its `mode` changed
and a decision-record reference added; none has diverged.

## What the sibling status means for claims here

At `42a8db0` the sibling reports tile RTL implemented and BEL-tested, its
routed tile DRC/LVS-clean, and timing characterized. It also reports
bitstream-level verification of the ratified fabric **not yet done**: only an
experimental single-tile harness test exists, run against a same-index
stand-in switch matrix, not the Wilton-class population its spec names (G5
open, G6 open, ADR-0004/0005/0006 *Proposed*).

Consequences for this port:

- The stamped switch-matrix RTL is that same stand-in. It is the starting
  point, not a verified Wilton-class matrix. This repo makes no
  routability or functional claim from the sibling's results.
- A functional claim here needs its own bitstream-level run on the simulated
  fabric in this repo.
- Sibling sky130 area, utilization, DRC/LVS and timing records are not
  evidence for SG13G2.
- The sibling's G5 and G6 gaps are inherited as open gaps.
